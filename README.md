# CommunityHub - Week 9

A React CommunityHub frontend built with React Router, API integration,
custom hooks, reusable components, and responsive styling.

## Features

- React Router navigation
- Home page
- Posts page
- Dynamic Post Detail page
- Create Post page
- About page
- JSONPlaceholder API integration
- Loading states
- Error handling
- Search posts
- Local post storage
- Reusable components
- Custom hooks
- Responsive design
- Accessibility improvements

## Technologies

- React
- React Router
- Vite
- JavaScript
- CSS
- JSONPlaceholder API

## Routes

- `/`
- `/posts`
- `/posts/:postId`
- `/create`
- `/about`
